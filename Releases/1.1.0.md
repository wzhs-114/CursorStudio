## What's new
- Separate lightweight tray and manager processes; closing or minimizing the window releases the manager while application rules continue running.
- Reopen the manager to restore themes, saved sizes, rules, language and preview preferences.
- Import the current Windows cursor scheme; improved cursor-pack recognition.
- Choose whether closing exits the program or keeps it in the tray; switch between English and Simplified Chinese.

The ZIP contains the manager and documentation only, without personal configurations or third-party cursor themes. Extract the entire archive and run CursorStudio.exe.

## 更新内容
- 将托盘后台与管理界面拆分：关闭或最小化窗口后释放界面，应用规则继续运行。
- 再次打开可恢复主题、大小预设、规则、语言和预览偏好。
- 支持导入当前 Windows 指针方案，改进指针包识别。
- 可选择关闭窗口时退出或保留托盘，并支持英文和简体中文切换。

压缩包仅包含管理器和说明，不包含个人配置或第三方指针主题。解压完整文件夹后运行 CursorStudio.exe。
